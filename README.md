# Spatiotemporal modeling of excess deaths attributable to underreporting-adjusted SARS-CoV-2 infection among USA state-level older populations

Data and code for:

> Lei J, Bettinger J, Irvine M, MacNab YC. Spatiotemporal modeling of excess deaths attributable to underreporting-adjusted SARS-CoV-2 infection among USA state-level older populations.

## Contents

- `data/analysis_data.RData` — compiled analysis dataset
- `code/` — R and Stan code for the analysis

## Data

The dataset was compiled from multiple publicly available sources. Variable definitions and source details are provided in the Supplementary Material of the manuscript.
